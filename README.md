# Cyber Threat Analytics Platform with Incident Visualization System

## Project Overview

This project presents a Power BI based Cyber Threat Analytics Platform designed to analyze cybersecurity incidents, assess security risks, and provide predictive and executive-level insights.

## Project Components

- Power BI Dashboard (.pbix)
- Project Documentation (.docx)
- Project Presentation (.pptx)

## Key Features

- Threat and incident analysis
- Security risk assessment
- Incident response analysis
- Predictive threat risk analysis
- High-risk zone identification
- Executive-level security insights

## Tools Used

- Power BI
- Power Query
- DAX
- Microsoft Excel
- Python / Data Analytics

## Project Milestones

1. Threat Classification & Severity Analytics
2. Incident Response Analytics
3. Security Risk Assessment
4. Predictive & Executive Intelligence
